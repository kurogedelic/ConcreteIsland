# 戦後日本復興シミュレーション

1945年から1970年までの日本の復興を体験する都市建設シミュレーションゲームです。

## 概要

焼け野原から始まり、高度経済成長期を経て近代都市へと発展させていく歴史的都市建設ゲームです。時代に応じた建物や技術がアンロックされ、朝鮮戦争特需や東京オリンピックなど、実際の歴史的イベントも発生します。

## 必要環境

- Python 3.8以上
- Pyxel 2.0以上

## インストール

```bash
# Pyxelをインストール
pip install pyxel

# 必要なアセットとフォントを配置
# babel_game/assets/以下にゲームアセット（PNGファイル）を配置
# babel_game/fonts/以下に日本語フォント（umplus_j10r.bdf）を配置
```

## 起動方法

```bash
cd babel_game
python main.py
```

## 操作方法

### 基本操作
- **F2キー**: 操作ヘルプ画面を表示

### カメラ操作
- **W/A/S/D** または **矢印キー**: カメラ移動
- **Z/X**: ズームイン/アウト
- **マウス**: カーソル移動

### 建設操作
- **左クリック**: 建物を配置/選択
- **右クリック**: 建物を削除
- **1-7キー**: 建物カテゴリ選択
- **マウスクリック**: パレットから建物を選択

### UI操作
- **Tab**: 情報パネル切り替え
- **P**: 建設パレット切り替え
- **G**: グリッド表示切り替え
- **Space**: 一時停止/再開

### 時間操作
- **Shift+1**: 速度0.5倍
- **Shift+2**: 速度1.0倍（標準）
- **Shift+3**: 速度2.0倍
- **Shift+4**: 速度5.0倍

### その他
- **F1**: デバッグ情報表示
- **F5/F6/F7**: 難易度変更（イージー/ノーマル/ハード）
- **Q**: ゲーム終了

## ゲームの特徴

### 歴史的建物（26種類）
- **1945年～**: バラック住宅、個人商店、派出所
- **1950年～**: 市営団地、商店街、小工場、小学校
- **1955年～**: 高層団地、百貨店、総合病院、国鉄駅
- **1960年～**: 高速道路、テレビ塔
- **1965年～**: 原子力発電所、空港

### 時代システム
- **終戦直後（1945-1950）**: 基本的な復興
- **朝鮮戦争特需（1950-1955）**: 経済ブースト
- **高度成長期（1955-1970）**: 急速な発展

### イベントシステム
- **災害**: 地震、台風、火災
- **経済イベント**: 朝鮮戦争特需、オイルショック
- **季節変化**: 春夏秋冬の変化

### 経済システム
- **月次精算**: 収入と支出は月末に精算
- **資源管理**: 米、鉄、木材、石炭、電力
- **貿易**: 資源の輸出入

## 難易度設定

- **イージー**: 初期資金15,000円、建設コスト-20%、収入+20%
- **ノーマル**: 初期資金10,000円、標準設定
- **ハード**: 初期資金5,000円、建設コスト+30%、収入-20%

## ゲームの目標

1970年までに繁栄する都市を築き上げることが目標です。ゲーム終了時には以下の要素で評価されます：

- 最終人口
- 最終資金
- 市民の幸福度
- 建物の数と種類
- 技術進歩の度合い

評価ランクはS～Eまであり、S評価は「奇跡の復興」と称されます。
