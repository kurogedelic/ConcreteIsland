## 1. ゲーム概要

### 1.1 ゲームビジョン
1945年、焼け野原となった日本の都市を復興する等角投影視点の都市建設シミュレーションゲーム。

### 1.2 コアゲームプレイループ
```
資源収集 → 建物配置 → 住民増加 → 新技術解放 → より大きな建物 → 都市発展
```

### 1.3 ターゲット層
- **プライマリ**: 都市建設ゲーム愛好者 (20-45歳)
- **セカンダリ**: 日本史・復興史に興味のある学習者
- **レトロゲーム愛好者**: ピクセルアート・等角投影ゲームファン

### 1.4 プラットフォーム仕様
- **エンジン**: Pyxel 2.x
- **解像度**: 800x600 (スケーラブル)
- **カラー**: 255色パレット + 透過PNG対応
- **入力**: マウス + キーボード

## 2. ゲームメカニクス

### 2.1 都市建設メカニクス

#### 2.1.1 建物配置システム
- **グリッドベース**: 等角投影32x32グリッド
- **建物サイズ**: 1x1, 2x2, 3x3, 4x4
- **地形制約**: 建物種別による配置可能地形
- **道路接続**: 自動パスファインディング

#### 2.1.2 建物種別
```
住宅系:
  - バラック住宅 (1x1) → 木造住宅 (2x2) → 鉄筋住宅 (3x3)
  
商業系:
  - 個人商店 (1x1) → 商店街 (2x2) → デパート (3x3)
  
工業系:
  - 小工場 (2x2) → 大工場 (3x3) → 近代工場 (4x4)
  
公共系:
  - 交番 (1x1) → 警察署 (2x2)
  - 診療所 (1x1) → 病院 (3x3)
  - 寺子屋 (1x1) → 学校 (2x2) → 大学 (4x4)
  
インフラ:
  - 道路 (1x1) - 16方向対応
  - 鉄道 (1x1) - カーブ・分岐対応
  - 発電所: 火力 (3x3) → 原子力 (4x4)
  - 上下水道 (1x1)
```

### 2.2 経済システム

#### 2.2.1 基本通貨
- **円 (¥)**: メイン通貨
- **米 (俵)**: 食料資源
- **鉄 (トン)**: 工業資源
- **木材 (束)**: 建設資源

#### 2.2.2 収入源
- **税収**: 住宅・商業建物から
- **工業生産**: 工場からの製品販売
- **貿易**: 港湾施設での輸出入

#### 2.2.3 支出
- **建設費**: 建物・インフラ建設
- **維持費**: 月間維持コスト
- **災害復旧**: 地震・火災からの復旧

### 2.3 住民システム

#### 2.3.1 住民属性
```python
住民クラス:
  - 年齢: 0-80歳
  - 職業: 農民, 工員, 商人, 公務員, 学生
  - 幸福度: 0-100
  - 技能レベル: 1-10
  - 健康状態: 健康, 負傷, 病気
```

#### 2.3.2 住民ニーズ
- **基本ニーズ**: 食料, 住居, 安全
- **文化ニーズ**: 教育, 娯楽, 宗教
- **社会ニーズ**: 雇用, 交通, 医療

### 2.4 時間システム

#### 2.4.1 時間進行
- **リアルタイム**: 1秒 = 1日
- **一時停止**: 建設時の戦略的停止
- **早送り**: 2x, 4x, 8x速度

#### 2.4.2 季節・災害
- **四季**: 農業生産量変動
- **災害**: 地震 (年1-2回), 火災 (稀)
- **イベント**: 朝鮮戦争特需 (1950年)

## 3. プログレッション

### 3.1 技術ツリー
```
復興初期 (1945-1950):
  ├── バラック建設
  ├── 基礎インフラ
  └── 農業復活

経済成長期 (1950-1960):
  ├── 軽工業発展
  ├── 鉄道網整備
  └── 教育制度

高度成長期 (1960-1975):
  ├── 重工業
  ├── 新幹線
  └── 高層建築
```

### 3.2 解放条件
- **人口達成**: 100人 → 500人 → 2000人 → 10000人
- **年度達成**: 1950年 → 1960年 → 1970年
- **特殊条件**: 大学建設 → 港湾整備 → 国際空港

## 4. ユーザーインターフェース

### 4.1 レイアウト
```
┌─────────────────────────────────────────────────────────┐
│ 年月日 | 人口: XXXX | 資金: ¥XXXX | 幸福度: XX%        │ ← ヘッダー
├─────────────────────────────────────────────────────────┤
│                                                         │
│                                                         │
│              メインゲーム画面 (等角投影)                   │
│                                                         │
│                                                         │
├───────────────────────────────┬───────────────────────────┤
│ 建設パレット                     │ 情報ウィンドウ              │
│ [道路][住宅][商業][工業]         │ 選択した建物の詳細情報       │
│ [公共][電力][交通][削除]         │ 住民情報, 生産量等          │
└───────────────────────────────┴───────────────────────────┘
```

### 4.2 操作方法
- **カメラ**: WASD移動, マウスホイールズーム
- **建設**: 左クリック配置, 右クリックキャンセル
- **パレット**: 数字キー (1-8) で建物選択
- **情報**: マウスオーバーで詳細表示
