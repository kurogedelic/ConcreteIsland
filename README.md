## 🎯 プロジェクト概要

1945年、焼け野原となった日本の都市を復興する等角投影視点の都市建設シミュレーションゲーム。
プレイヤーは市長として、バラック住宅から始まり、高度経済成長期の高層建築まで、
25年間の復興の歴史を体験します。

### 🏛️ 歴史的テーマ
- **1945-1950**: 戦後復興期（バラック住宅、基礎インフラ）
- **1950-1955**: 朝鮮戦争特需期（軽工業発展）
- **1955-1970**: 高度成長期（重工業、高層建築、原子力）

### 🎮 主要機能
- **建物システム**: 40種類の歴史的建物、年代順アンロック
- **住民システム**: 人口成長、幸福度管理、職業システム
- **経済システム**: 円・米・鉄・木材の資源管理
- **イベント**: 災害、特需、季節変化
- **完全日本語対応**: 日本語フォント、UI、テキスト
